Interspeech.cls is unmodified. Its author credits are retained. The Overleaf template lists CC BY 4.0; the project code license does not supersede third-party template rights.

main.tex uses the named-author camera-ready layout for drafting, not a claim of acceptance. For review, switch to the anonymous class option and remove identifying project/repository references and supplementary metadata. No submission has been made. Venue policy, including restrictions on significant AI-generated manuscript content, requires author review; a disclosure does not itself establish compliance.

Current PDF: 5 pages including references; main content ends on page 4. Standard class margins, 9-point Times body, two columns, no custom geometry. The full-width table starts page 3. Complete aggregate comparisons are preserved in supplementary.tex/pdf as reproduction materials. The venue restricts supplementary use and says it must not circumvent paper length; this separate file is not represented as automatically eligible review supplementary material. Essential results are in the main paper.

Build from this directory with pdflatex main.tex twice and pdflatex supplementary.tex twice. main.tex requires the bundled Interspeech.cls. Previous single-column files remain in local ignored revisions/pre-interspeech.
