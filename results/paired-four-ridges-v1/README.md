# Paired four-approach results

All 305 recordings are matched by ID, with exact agreement of human and Azure scores between exports. No private rows are included. Both seeds use 1,200,000 paired resamples; 510 contrasts receive a common Bonferroni correction. Seven decisions differ between seeds and are marked borderline. The main leader conclusions are stable.

B-S aesopocean fluency correlation exceeds human and Azure agreement; its QWK exceeds Azure but is not significantly above the human baseline. B-D koreanaesop prosody correlation exceeds both baselines. The small new maxima over previous S/D/H leaders are not statistically established. S-koreanocean and B-S-koreanocean accuracy QWK remain above human agreement.

`paired-all-conditions.csv` contains both ordinary and adjusted intervals. `summary.json` identifies borderline comparisons. The preserved 258-contrast archive is superseded for current-paper inference by this expanded family; its prior intervals should not be mixed with the new correction.
