Approximately 58 draws fall in each adjusted tail, so endpoints remain Monte Carlo approximations. Correction covers these contrasts, not the preceding model search or direct comparisons between selection rules; inference conditions on the observed panel and fitted models. No private scores were used for fitting or calibration.
