Matched-cohort master tables
Human–human pairwise agreement = mean of h1–h2, h1–h3 and h2–h3 statistics. Human–other-rater consensus agreement = mean of each human’s agreement with the mean of the other two humans; a human never contributes to their own reference. Both summaries are recomputed within every bootstrap replicate, averaging the three statistics rather than pooling observations. Each system has two rows: three-rater consensus uses the mean of all three humans; two-rater consensus averages the three agreement statistics against the three possible two-human means. These statistics are recomputed within every bootstrap replicate, not calculated after pooling or averaging the reference means. Compare the two-rater system row with human–other-rater consensus on the matched cohort for the same references and recordings. Available-data rows may use different recordings, so those human/model differences are not a matched comparison. Within each construct, all available methods and humans use the same complete recordings. Pending methods are blank; tables are provisional until all requested methods have results. 95% intervals are percentile speaker-cluster bootstrap intervals, conditional on these raters and fitted models; they are not intervals for differences or multiple-comparison-adjusted tests. The default treats each distinct Drive ID as one speaker. Use --speaker-column COLUMN if a speaker has multiple recordings. QWK uses fixed 0–100 integer categories, half-up rounding; API scores are multiplied by 10 before analysis. Predictions are capped at 0–100 for QWK only, including bootstrap replicates; raw scores are retained for Spearman. Clipped counts refer to the displayed row cohort. No calibration is fitted. SpeechOcean scores are imported from the original s- columns; their API version is unspecified. No ± run variability is shown because these are single fitted models. Bold identifies human baseline rows and both rows of any system within 0.001 of the best system Spearman or QWK in either reference type. Eligibility uses unrounded estimates, separately by construct, metric and reference type. A bold row does not mean every value in it is near-best. This is visual grouping, not statistical equivalence, significance, or a matched-cohort advantage in available-data tables.
